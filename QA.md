# Выполненные проверки

Проверено в headless Chromium через Playwright, с локальной HTTP-раздачей проекта. В первом прогоне внешний SDK был недоступен — проверялся браузерный fallback. Во втором использовалась имитация WebApp SDK, не реальный клиент Telegram.

## Пройденные сценарии

1. Крокодил: слово меняется, таймер истекает, +1 в таблице.
2. Элиас: исправление статуса, общее слово, распределение +2/+1.
3. Шпион: приватность hold/release, раздача 6 ролей, раскрытие.
4. Правда/действие: смена карты без повторения, очередь игроков.
5. Я никогда не: следующая карта и счётчик.
6. Кто я: 3–2–1, карточка, таймер, результаты.
7. Бункер: раздача 8 карточек, открытие характеристики, исключение.
8. Мафия: раздача, сценарий ночи, роли, дневной таймер, исключение.
9. 18+: неверный ответ отклонён, верный включает режим, настройка переживает перезагрузку.
10. Выход из активной игры: отмена сохраняет матч, подтверждение возвращает в меню.
11. Storage: три карты до исчерпания выдаются без повторов, затем начинается новый круг.
12. Главный экран: нет горизонтального переполнения на 390, 844 и 1280 px.
13. Telegram SDK mock: ready/expand, dark theme, native BackButton; 5/4 сек medium, 3/2/1 heavy, конец error + heavy×2.
14. Telegram SDK mock: смена темы через themeChanged.

15. Мафия: при нуле простых мафиози Дон участвует в общем ночном убийстве; дневной таймер продолжает идти после раскрытия списка ролей.

## Дополнительно

- Все JavaScript-файлы проходят `node --check`.
- Все восемь модулей игр загружаются и показывают рабочий экран настройки.
- Все массивы проверены на дубликаты внутри набора без учёта регистра.
- Для каждого набора проверен фактический объём через импорт ES Modules в браузере.
- Не зафиксировано необработанных pageerror в описанных прогонах.
- После форматирования повторно выполнены проверка синтаксиса и открытие всех игр.

## Не проверено

- Реальные клиенты Telegram iOS, Android, Desktop.
- Физическая вибрация, системные ограничения фоновых таймеров.
- Safari и Firefox.
- Все возможные комбинации настроек и все игровые исходы: автоматические проверки не равнозначны исчерпывающему тестированию.
