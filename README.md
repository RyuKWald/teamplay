# Круг — Telegram Mini App

Восемь русскоязычных pass-and-play игр. Один телефон, без регистрации, серверной части, npm, сборки и API-ключей. Все пути относительные, поэтому сайт работает в подпапке репозитория GitHub Pages.

## Запуск

Для GitHub Pages просто загрузите содержимое проекта в корень репозитория. `index.html` должен оказаться именно в выбранной папке публикации, а не внутри дополнительной папки `krug`.

Для локальной разработки из папки проекта:

```sh
python3 -m http.server 8080
```

Откройте `http://localhost:8080`. Не открывайте `index.html` через `file://`: проект использует ES Modules.

## GitHub Pages

1. Создайте репозиторий и загрузите все файлы с сохранением папок.
2. В Settings → Pages → Build and deployment выберите Deploy from a branch.
3. Выберите main и /(root), затем Save.
4. После окончания публикации откройте адрес, который покажет GitHub Pages. Обычно это `https://USERNAME.github.io/REPOSITORY/`.
5. Проверьте все игры и отсутствие ошибок загрузки JS/CSS в консоли.

`.nojekyll` отключает обработку Jekyll; у этого файла намеренно нет содержимого.

## BotFather

1. Откройте @BotFather и создайте бота через /newbot, если его ещё нет.
2. Отправьте /setmenubutton, выберите бота, укажите HTTPS-адрес опубликованного сайта и подпись кнопки, например «Играть».
3. Альтернативный путь: /mybots → ваш бот → Bot Settings → Menu Button.
4. Для основной Mini App в профиле бота используйте Bot Settings → Configure Mini App и укажите тот же URL. Названия пунктов могут отличаться в интерфейсах BotFather.
5. Откройте личный чат с ботом и нажмите кнопку меню.

Бот-токен в этом проекте не нужен. Не размещайте его на GitHub или в JavaScript. Сервер для запуска самой Mini App и кнопки меню не требуется; обработчик сообщений бота в этот проект не входит.

## Архитектура

- index.html: SDK и модульная точка входа.
- css/styles.css: светлая/тёмная темы, стекло, сетка, landscape для игры «Кто я».
- js/app.js: каталог, навигация, цвета, жизненный цикл игры, подтверждение выхода.
- js/telegram.js: guarded SDK, браузерный fallback, BackButton, темы и вибрации.
- js/storage.js: настройки и история слов в localStorage. При недоступном хранилище используется память.
- js/ui.js: безопасное создание DOM без вставки пользовательского HTML, формы, диалоги, свайпы, таймер и приватная раздача.
- js/settings.js: включение взрослых колод через задачу и очистка истории.
- js/data/: полные статические массивы, без генерации контента во время игры и без запросов к AI.
- js/games/: восемь независимых точек входа; team-engine.js объединяет только общие механики Крокодила и Элиаса.

## Базы

| Игра | Объём |
|---|---|
| Крокодил | 7 обычных категорий × 60 + ровно 100 взрослых карточек |
| Элиас | 4 набора × 80 |
| Шпион | 50 локаций |
| Правда или действие | 3 режима × (50 правд + 50 действий) |
| Я никогда не | 3 колоды × 60 |
| Кто я | 6 категорий × 50 |
| Бункер | 40 профессий, 36 комбинаций пола/возраста, по 30 остальных 6 характеристик; 30 катастроф; по 10 вариантов площади, срока, запасов и особенности |
| Мафия | 7 ролей с описаниями и сценарий ночи |

Некоторые слова намеренно встречаются в базах разных игр, но внутри каждой колоды дублей нет. В смешанном наборе одинаковые строки дедуплицируются. В словесных играх доступная карта выбирается случайно среди неиспользованных — это эквивалентно вытягиванию из перемешанной колоды. После полного исчерпания активного набора появляется уведомление и начинается следующий круг. При изменении набора сбрасываются только исчерпанные доступные карты, а не история остальных наборов. История сохраняется и между перезагрузками; очистить её можно в настройках. В Бункере характеристики уникальны внутри раздачи, катастрофы не повторяются до исчерпания 30 вариантов; составные параметры самого бункера могут совпадать.

## Правила и продуктовые решения

- Крокодил: пропуск без штрафа, очки начисляются при подведении итогов раунда. Одиночный режим тоже имеет цель по очкам.
- Элиас: отрицательный счёт допустим. Сначала проверка всех отмеченных слов, затем, если включено, распределение общего последнего слова. Очки применяются один раз. При одновременном достижении цели равным счётом объявляется ничья.
- Шпион: шпионов строго меньше половины игроков. После таймера роли не раскрываются автоматически — сначала принимается общее решение.
- Правда или действие: список редактируется строками, одно имя на строку. Случайная очередь без повторения игрока до конца круга. Любое задание можно сменить или пропустить.
- Я никогда не: без обязательного алкоголя, с правом не отвечать.
- Кто я: вопросы с ответами «да»/«нет», три секунды на подготовку; landscape перестраивает кнопки по краям.
- Бункер: мест floor(N/2). Характеристики открываются тумблерами на общем экране, особые карты разыгрываются по тексту по договорённости. Голосование и обмены характеристиками проводятся участниками, ведущий при необходимости интерпретирует эффекты. Статус здоровья — вымышленный игровой параметр, а не оценка ценности реальных людей.
- Мафия: нужен отдельный ведущий, не входящий в число игроков. Приложение помогает со сценарием, таймером и учётом выбывших, но не рассчитывает ночные действия и победителя. Простых мафиози можно поставить 0, если включён Дон. Дон считается членом мафии. Проверка баланса отсекает отсутствие мафии, отрицательное число мирных и стартовое преимущество враждебных ролей; это не математическая гарантия равной вероятности победы. Вариант локальных правил описан в помощнике ведущего.

## Безопасность и ограничения

1. Математическая задача — только бытовой барьер от случайного включения, а не подтверждение совершеннолетия. Данные колод открыты в исходном коде статического сайта. Взрослые колоды посвящены отношениям и флирту, без откровенных сцен.
2. Закрытая карточка защищает от случайного подсматривания, а не от человека с DevTools или доступом к памяти устройства. При отпускании кнопки, потере фокуса или сворачивании карточка скрывается. Ведущий Мафии может открыть общий список ролей отдельной кнопкой; при потере фокуса список скрывается.
3. История, команды и настройки хранятся локально и не синхронизируются между устройствами. Активная партия не восстанавливается после перезагрузки; история карт и настройки сохраняются.
4. Таймер считает оставшееся время по абсолютному дедлайну Date.now(), а не вычитает единицу за каждый tick. В фоне браузеры и Telegram могут приостанавливать JS: истечение времени учтётся после возврата, но гарантировать вибрации при свёрнутом приложении нельзя.
5. Вибрация зависит от устройства, версии Telegram и системных настроек. Браузерный navigator.vibrate поддерживается не везде. Кнопки и таймер работают и без физической вибрации.
6. Приложение не отправляет команды, имена, роли или результаты по сети. Единственный внешний скрипт — официальный Telegram WebApp SDK. initData не используется для авторизации; ценных серверных операций в проекте нет.
7. Полного офлайн-кэширования нет: service worker не добавлен, SDK загружается с telegram.org.
